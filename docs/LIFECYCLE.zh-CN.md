# 存储、安全与生命周期

[English](LIFECYCLE.md) · [项目介绍](../README.zh-CN.md) · [技术文档](TECHNICAL.zh-CN.md)

## 原子创建

EDGEDICE 保留原占位符；解析、渲染不出点。CommentPost 创建时收集有效范围、校验数量，以 random_int 生成结果，并在同一次 INSERT 写入 posts.edge_dice。没有掷骰／预览 API、客户端种子或可信客户端结果，服务器和数据库属于信任边界。

可空帖子字段避免孤立记录：永久删除帖子／讨论时，即使插件停用或移除，结果也随行删除。安装只为旧行增加 NULL，不改正文、不补掷。

## 编辑

沿用 Flarum 权限。allowEdit 默认开启；saving 钩子先恢复数据库账本，忽略客户端／模型指定结果。序列不变时逐字节保留；变化时相同范围按出现顺序 FIFO 复用，即使移动也一样，无法复用的范围只在保存路径出点。新账本清除未引用结果。新帖和变化序列受数量上限约束；非空账本损坏时拒绝编辑，不静默重掷。

序列变化标记所有剩余骰子，包括复用项，因为删除也可能筛选结果。全部删除只保留 `{v:1,rolls:[],edited:true}`，后续增加继续标记。markEdited 只控制展示。用户主动编辑旧帖加入占位符可出点并标记。

关闭 allowEdit 后，已掷帖必须保持整个范围序列，叙述和空白可改；未掷旧帖编辑后仍不出点。整帖删除沿用原权限。相同范围不可区分，不证明周围叙述未变、不阻止删帖重发、不提供独立于管理员的公平证明。并发编辑沿用站点保存行为，不新增历史或锁。

## 预览与休眠恢复

新预览显示问号。编辑预览按 FIFO 复用已知范围，其余待掷；严格模式下非法变化给出简短警告。输入框和富文本编辑面不增强。

浏览／重装不补掷。停用期间可能失去 formatter 标签，渲染会在内存中重解析有账本的帖子；仅整个范围序列匹配才显示，否则休眠。恢复原序列可恢复显示；开启编辑后主动保存则按编辑规则协调。

## 禁用、移除、卸载

1. 操作前备份数据库。
2. 正常禁用并重建 Flarum 缓存／资源，再用 Composer 移除；旧标签退回原占位符，不依赖插件代码。
3. migration down 保留 posts.edge_dice。后台卸载删除迁移记录但保留结果；重建不含 Dice 的资源后移除内嵌遮罩。
4. 重装启用时 migration up 检查已有列，重建 formatter／前端，不重掷。

彻底销毁结果需先导出帖子 ID／账本，停用移除后由 DBA 显式删除正确前缀 posts 表的 edge_dice 列。这是不可逆操作，插件不自动执行。

## 代码回退

当前继续使用 v1 `[min,max,result]` 元组，增加可选布尔 edited。最初 beta.1 可显示结果但忽略标记；回退代码恢复旧的严格编辑和展示。恢复旧数据库会丢失后续合法帖子／编辑，不是常规代码回退。

## 安全与兼容

- Flarum ^2.0.2／PHP ^8.3，不支持 1.x；排除代码、引用、链接标签，不支持任意表达式。
- XML 使用 LIBXML_NONET、拒绝 DOCTYPE；结果属性由账本替换。颜色只接受十六进制／空，标签为有限纯文本；顺序、数值、布尔、图标结构由服务端校验。
- 字体图标仅一个已知 FA 样式类和图标类；图片仅根相对或无凭据 HTTP(S)，包括未启用配置也拒绝 data、协议相对 URL、脚本。浏览器不发送 referrer，无服务端抓取。
- 不新增权限、令牌、账号、会话、定时任务或系统／网络配置。自定义图片可引用外部主机。支持常见深色 data-theme 和 .dark，自定义主题可能覆盖变量。

## 设置升级和提示

数量／百分比阈值分别保留，只影响展示。百分比按闭区间面数向下取整，至少 1 个，每端最多面数一半。旧设置无 mode 时，仅有 criticalPercent 而无 criticalCount 才推断百分比，否则数量；显式模式优先。

旧 digitsMin 在内存展开为 repeatDigitsMin／sequenceDigitsMin，显式新字段优先，新默认值 2／3。保存写归一化字段，加载不改库。中文默认词为连号／同花顺，内部键、自定义词、颜色、账本不变。

指针按下不取得焦点，并清除已有键盘焦点以免提示停留；Tab 和悬停保留，不直接操作 Bootstrap tooltip。
