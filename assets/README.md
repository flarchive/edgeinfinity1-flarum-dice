# Dice artwork

[Introduction](../README.md) · [中文介绍](../README.zh-CN.md)

The seven `die_*.png` files were supplied by the project owner for this extension, including reviewed d8/d20 replacements. They accompany the project under its existing [MIT license](../LICENSE). No third-party replacement artwork is bundled.

`less/icons.less` embeds their alpha masks so built-in dice inherit configured colors without external image requests or archive-directory dependencies. Custom ordinary image URLs are configured separately.

Documentation screenshots are browser captures with illustrative data; they contain no real user posts or saved administrator sessions.
